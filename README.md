# ♡ HeartLock PAD ♡

A simple, lightweight notepad application for writing, editing, and keeping your notes.

## About

**HeartLock PAD** is a desktop notepad app built around a simple writing experience. It keeps note-taking straightforward while giving the classic notepad concept its own visual identity.

## Features

* Create and edit notes
* Open text files
* Save your notes
* Simple text editing
* Lightweight desktop application
* Clean HeartLock interface
